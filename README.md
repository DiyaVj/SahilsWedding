# Wedding_Sahil

This is a small wedding greeting page themed and personalized for Sahil. Edit the HTML, images, or audio to swap in wedding photos and music.

Photos for collage
------------------

To add your 3 photos to the collage shown after the message section, place them in a `photos/` folder at the project root and name them `photo1.jpg`, `photo2.jpg`, and `photo3.jpg` (or update the `src` attributes in `index.html` to your filenames).

Example:

```
photos/photo1.jpg
photos/photo2.jpg
photos/photo3.jpg
```

If you'd like different layout/spacing or a lightbox effect for the photos, I can add that next.

When the collage is shown
------------------------

The collage is intentionally hidden by default and will automatically appear at the end of the message/story sequence (after you use the on-screen controls and click "A message for Sahil" to play the message). If you'd like the collage revealed earlier (for example, after the cake animation or on a button press), I can change that behavior.
